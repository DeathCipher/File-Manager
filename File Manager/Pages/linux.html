Browser-based file manager

Browse, search, and edit a directory directly from your browser.

This application uses the File System Access API for full read/write access. It works in Chromium-based browsers on Linux — Chrome, Edge, Brave, Vivaldi, Opera, and others. In other browsers, such as Firefox, it automatically falls back to a read-only preview mode. Nothing is ever uploaded; everything happens on your machine.
